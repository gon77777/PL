# きゅうり動画 — Android 版

Electron 版を Capacitor(WebView) に移植したプロジェクトです。
ffprobe/ffmpeg の代わりに `mkv-subs.js`（純 JS の Matroska パーサ）で字幕・音声トラックを取得します。

## APK のビルド方法

### A. GitHub Actions（PC に Android 環境不要）
1. このフォルダを GitHub リポジトリに push
2. Actions タブ → "Build APK" → Run workflow
3. 完了後、Artifacts から `app-debug.apk` をダウンロードして端末にインストール

### B. ローカル（Node 20 / JDK 17 / Android SDK が必要）
```
npm install
npx cap add android
npm run android:patch   # ネイティブ機能（小窓再生など）を組み込む
npm run build:apk
# → android/app/build/outputs/apk/debug/app-debug.apk
```

## 再生エンジン: libVLC（v2.0）
再生は端末の WebView(`<video>`) ではなく **libVLC**（VLC の再生エンジン）で行います。
mp4 / mkv / avi / wmv / flv / ts / m2ts / mpg / vob / rmvb / mov / webm / 3gp など、ほぼ全ての形式と、
HEVC・AV1・VP9・AC3・DTS・FLAC など主要なコーデックに端末の対応状況に関係なく対応します（ハードウェアデコード優先、不可ならソフトウェアに自動切替）。

- 映像は **WebView の背面にネイティブ描画**し、操作画面(HTML)をその上に重ねています（UI・小窓・全画面・ダブルタップスキップは従来どおり）
- `www/native-video.js`: libVLC を `<video>` 風の API で操作するラッパー。`#videobox` の位置を常にネイティブへ通知
- **「このアプリで開く」に対応**: ファイルマネージャー・LINE・ブラウザの保存先などから動画を直接開けます（開く / 共有 の両方。起動中でも新しい動画に切り替わります）。
  マニフェストへの追記は `scripts/patch-android.js` が行います（`application/octet-stream` も受けるので、種類が判別されない mkv 等も開けますが、アプリ選択欄には他のファイルでも出ます）
- ファイル選択は OS の標準ピッカー（拡張子で絞らないので全ファイルを選べます）
- 音声トラックは実際に切り替え可能。字幕は、MKV のテキスト字幕は従来どおり HTML で表示（タイムライン連動）、
  画像字幕(PGS/VobSub)や MP4 内蔵字幕などは libVLC が描画します
- **画面ロック（誤タップ防止）**: 操作部の鍵ボタンでタッチ操作を無効にします。ロック中にタップすると解除ボタンが出るので、長押し（約1秒）で解除。戻るボタンも無効です（通知・イヤホンの操作は有効）
- **イヤホンを抜く / Bluetooth が切れると自動で一時停止**（設定でオフ可）
- **通知・ロック画面・イヤホンからの操作**: 再生中は通知（メディア通知）に「戻る / 再生・一時停止 / 進む」ボタンとシークバーが出て、ロック画面からも操作できます。Bluetooth イヤホン等の再生/一時停止・次へ・前へボタンにも反応します
  （戻る/進むの秒数は 設定 →「操作・再生」のスキップ秒数）。アプリが見えなくなっても（画面ロック中も）音声は再生し続けます。Android 13 以降は初回の再生時に通知の許可を尋ねます
  実装: `NativePlayerPlugin.java`（MediaSession・通知）と `PlaybackService.java`（前面サービス）、`MkvScanner.java`（MKV 字幕走査）。権限・サービスの宣言は `scripts/patch-android.js` が追記します
- **バックグラウンド再生（ラジオ代わりに聞く用途）**: 画面を消す・ホームへ戻る・他のアプリに切り替えても音声は再生し続けます。画面から見えない間は映像のデコードを止めて電池消費を抑え、アプリに戻ると映像を復帰します。
  設定 →「画面を消しても音声を再生し続ける」をオフにすると、アプリを離れた時点で一時停止します（通知からは再開可能）
  画面を消して戻ったときは、映像用ビューを付け直してから映像を復帰します（先に復帰させると映像出力が作られず音声のみになるため）
- **再生位置の記憶と自動掃除**: 動画ごとの再生位置を保存し、次に開いたとき続きから再生します（5 秒以降まで見ていた場合）。最後まで見た動画の記録は消え、次回は頭から再生します。
  動画本体のキャッシュは作りません。元の動画が消されたかはアプリから分からないため、**90 日以上開いていない記録**と、**新しい 200 件より古い記録**を自動で削除します（起動時と保存時）
- **A-B リピート**: コントロールの「A-B」ボタンで、1回目=A 地点、2回目=B 地点を設定して区間をくり返し再生、3回目で解除（キーボードは `A`）。シークバーに区間が表示されます。ループは端末側で処理するので、画面を消していても動きます。動画を切り替えると一度解除されますが、最後に使っていた区間は動画ごとに記憶され、開き直すと自動で復元されます（下の「タイムスタンプ・A-B の保存」参照）
- **プレイリスト / 連続再生**: ファイル選択で動画を長押しして複数選ぶと、ファイル名順（数字は自然順: 1, 2, 10）のプレイリストになります。右下のプレイリストボタンから一覧・追加・削除・タップ再生ができます。
  **連続再生は既定でオフ**です（設定、またはプレイリスト画面のスイッチでオン）。オンのとき、最後まで再生すると次の動画へ自動で進み、最後の動画で止まります。曲の切れ目でも前面サービスを維持するので、画面を消したままでも途切れません。
  通知・ロック画面・イヤホンの「次へ / 前へ」は、プレイリストが 2 本以上あるときは曲送りになります（「前へ」は 3 秒以降なら頭出し）。プレイリストは保存されず、アプリを終了すると空になります
- **MKV 字幕の高速読み込み**: 字幕・音声トラックの解析は `MkvScanner.java`（ネイティブ）で行い、大きな映像ブロックは読まずに飛ばします。数 GB の動画でも短時間で終わります（読み込み中はタイムラインに「字幕を読み込み中…」と表示）。
  ネイティブ側が使えない・失敗した場合は、従来の JS 走査（`mkv-subs.js` の `extract`）に自動で切り替わります。最初の字幕トラックが画像字幕などでテキストが無いときは、テキスト字幕のあるトラックをタイムラインに出します
- **オーディオフォーカス対応**: 通話の着信・アラームなど一時的な割り込みでは自動で一時停止し、終わると自動再開します。他の音楽アプリが再生を始めたら一時停止（自動再開はしません）、通知音などの間は音量を下げます。ミュート中はそのまま維持されます
- **イコライザー（10 バンド）**: コントロール 2 段目の「EQ」ボタンで開きます（全画面中でも開けます。戻るボタン / 「閉じる」で閉じる）。
  libVLC 標準のイコライザーで、60 / 170 / 310 / 600 / 1k / 3k / 6k / 12k / 14k / 16k Hz を ±12 dB（0.5 dB 刻み）で調整でき、プリアンプも付いています。
  プリセットを選ぶかスライダーを動かすと自動でオンになり、ON の間は EQ ボタンが強調表示されます。再生中の音にその場で反映され、動画を切り替えても、画面を消しても、映像復帰でメディアを開き直しても設定は保たれます。
  - **プリセット**: 「標準」= libVLC 内蔵（クラシック / クラブ / ダンス / 重低音 / 高音強調 / ヘッドホン / ホール / ライブ / パーティー / ポップ / レゲエ / ロック / スカ / ソフト / ソフトロック / テクノ など。端末側から取得）＋ このアプリ独自の「ボイス強調（セリフ・会話）」「低音カット（小さいスピーカー）」
  - **マイプリセット**: 名前を入力して「保存」（同じ名前は上書き、最大 30 件）。「削除」で消せます
  - 設定（ON/OFF・プリアンプ・各バンド・マイプリセット）は端末に保存され、次回起動時に自動で反映されます
  - 音が割れるときはプリアンプを下げてください。Bluetooth などの出力先に関係なく効きますが、HDMI 等のパススルー出力（AC3/DTS をそのまま出力）では効きません
  - 実装: `www/equalizer.js`（画面・プリセット・保存）、`NativePlayerPlugin.java` の `vlcEqInfo` / `vlcEqSet`（`MediaPlayer.Equalizer`）、`android-shim.js` の `eqInfo` / `eqSet`
- **コンプレッサー（音量の均一化）**: コントロール 2 段目の「COMP」ボタンで開きます。大きい音を抑えて小さい音を持ち上げ、「セリフは小さいのに爆発音だけ大きい」状況を和らげます（libVLC の音声フィルター `compressor`）。
  - **プリセット**: 弱 / 標準（映画・ドラマ向け）/ 強 / 夜間。選ぶと自動でオンになります
  - **手動調整**: しきい値・圧縮比・アタック・リリース・ニー・出力ゲイン・検出方式(RMS↔ピーク)。触ると「カスタム」になり自動でオン。スライダーは**指を離したときに 1 回だけ**適用します
  - **注意**: 再生中に値を変える API が無いため、適用のたびに**同じ位置・同じ再生状態で動画を開き直します**（音が 0.5〜1 秒途切れ、映像も一瞬乱れます）。設定は端末に保存され、次回起動時に反映されます
  - **バイパス / リセット**: 右上の「効果」スイッチをオフにすると、設定を残したまま効果なし（バイパス）になります。「リセット」で初期値（標準）に戻せます（EQ も同様: 「効果」でバイパス、「リセット」でフラットに戻す）
  - イコライザーとの併用時の相性・フィルターの順番は、実機での確認が必要です
  - 実装: `www/compressor.js`（画面・プリセット・保存）、`NativePlayerPlugin.java` の `vlcCompSet`（Media オプション `:audio-filter=compressor` ＋ `reloadMedia()`）、`android-shim.js` の `compAvailable` / `compSet`
- **音量ブースト（最大 200%）**: COMP 画面に常に 100〜200% のバーがあります（既定 100% = 変化なし。「100%」ボタンで戻せます）。再生中にその場で反映され、途切れません。倍率は `window.__volGain` 経由で `native-video.js` の音量に掛けています（libVLC の上限 200%）。100% を超えると音が割れることがあります
- APK は libVLC を含むため大きくなります（arm64 / armv7 のみ。x86 エミュレータでは動きません）
- ブラウザなどネイティブ機能が無い環境では、従来どおり `<video>` で再生します

## Electron 版からの変更点
- `www/android-shim.js`: `window.electronAPI` を Android 向けに再実装（ファイル選択 / 設定・再生位置は localStorage 保存）
- `www/player.js`: ファイルパスの代わりに File オブジェクトを扱う 3 箇所のみ修正
- `www/android.css`: 縦持ち/横持ちレイアウト、全画面・小窓表示、デスクトップ専用UI（最前面・ショートカット等）の非表示
- タイムライン別窓・Always on Top・キーボードショートカットはモバイルでは無効

## Android 固有機能（v1.1）
- **2段構成のコントロール**: ボタンが画面幅からはみ出さない。シークバーは指のドラッグに対応
- **音量バーなし**: 音量は端末の音量キーで操作（アプリ内音量は 100% 固定、ミュートボタンのみ）
- **全画面ボタン / 画面の向きボタン**: 全画面はステータスバー等を隠し、再生中は操作部が自動で隠れる（タップで再表示）。横長動画を縦持ちで全画面にすると自動で横向きに
- **小窓再生（PiP）**: 再生中にホームへ戻ると小窓に移行。小窓の再生/一時停止ボタン、×で停止。ボタンからも手動で小窓にできる（設定でオフ可）
- **ダブルタップでスキップ**: 左半分=戻る / 右半分=進む。続けてタップすると連続スキップ。秒数は 設定 →「操作・再生」で変更（1〜300秒）
- 再生中は画面が消灯しない

### ネイティブ部分の仕組み
`android/` は `npx cap add android` で毎回生成されるため、ネイティブ機能は `native/android/` に置き、
`scripts/patch-android.js` が生成後の `android/` へコピーしてマニフェストを更新します（何度実行しても同じ結果）。

## テーマ / アイコン
- テーマは **Mono のみ**（Cute テーマと切替ボタンを削除）。フォントも端末標準に統一し、外部フォント読み込みをなくしました。
- アプリアイコンの元画像は `assets/icon-source.png`。各解像度に書き出した PNG は `native/android/res/` にあり、`npm run android:patch` で `android/` へ反映されます（アダプティブアイコン対応・背景は白）。

## 映像の復帰（画面消灯 / 小窓 / 手動）
- `recoverVideo()`（NativePlayerPlugin.java）に一本化。固定の待ち時間ではなく、**映像出力(Vout)が閉じたのを確認してから**トラックを戻します
  （デコーダの後始末が終わる前に戻すと無視されて黒いままになるため）。
- 戻らなければ段階的に強くします: レベル 0（トラックの入れ直し）→ 1（映像用ビュー SurfaceView ごと作り直し）→ 2（メディアを開き直して同じ位置・再生状態・速度・音声/字幕で再開）。
- **小窓のまま画面を消した場合**は、トラックを切らないまま描画面だけ失われてデコーダが不安定になるので、復帰時に最初からレベル 2 で復帰します。
- コントロールの「映像を再読み込み」ボタン（回転矢印）は、常にレベル 2 を実行します（音声が一瞬途切れます）。
- 復帰にかかった時間はトースト表示されます（`native-video.js` の `SHOW_RESUME_TIMING`）。

## スキップの単位（秒数 / フレーム）
- 設定 →「操作・再生」→「スキップの単位」で切り替えます（既定は秒数）。
- 「フレーム」にすると、**ダブルタップ**と **◀|▶ ボタン**（旧 ±5 秒）が、「1回で動かすフレーム数」(1〜300、既定 1)ぶんのコマ送り／コマ戻しになります。再生中は一時停止して動かします。±30 秒ボタンと通知の「戻る/進む」は秒数のままです。
- 実装: `NativePlayerPlugin.java` の `vlcStepFrame`。1 フレーム進むだけは libVLC の `nextFrame()`（効かない端末は時間指定のシークで代用）。それ以外（戻る・複数フレーム）は、動画の fps から求めたフレーム間隔×枚数ぶん精密シークします（VLC に逆送りが無いため）。fps が取れなければ 30fps とみなします。


## くり返し再生

- 設定（とプレイリスト画面）の「くり返し再生」で、しない（既定）/ 1 本をくり返す / プレイリスト全体をくり返す を選べます。選択は保存されます。
- 「1 本」は、最後まで再生したら同じ動画を頭から再生し直します。「全体」は、最後の動画のあと先頭へ戻ります（連続再生がオフでも次の動画へ進みます。通知・ロック画面の「次へ」も最後から先頭へ戻ります）。動画が 1 本だけのときは、その動画をくり返します。
- A-B ループ（区間のくり返し）とは別機能です。A-B 中は区間をくり返し続けるので、動画の終わりまで進みません。
- 画面を消している間も続くよう、リピート中は終了後も前面サービスを維持します（連続再生と同じ仕組み）。
- 実装: `player.js`（`repeatMode` / `setRepeat()` / `ended` 処理）

## 帯域ソロ（聴き分け）— イコライザー画面

- 「ベース」「ボーカル」「高域」のボタン、または各フェーダー下の「S」（複数選択可）で、選んだ帯域以外を -20 dB（libVLC の下限）まで下げ、その帯域だけを意識して聴けます。完全には消えません。
- 端末へ送る値を一時的に差し替えるだけで、フェーダー・プリセット・保存内容は変わりません。ソロは保存されず、アプリを開き直すと解除されます。EQ の「効果」がオフでもソロは効きます。
- 実装: `www/equalizer.js`（`effective()` が端末へ送る値を作る）、`index.html` / `android.css`（ボタン）

## タイムスタンプ・A-B の保存

- 字幕タイムラインのヘッダーがタブ（字幕 / タイムスタンプ / A-B）になっています。設定でタイムラインを非表示にしている場合はタブも見えません。
- **タイムスタンプ**タブ: 「＋ 今の位置を保存」で現在位置を保存します（名前は「タイムスタンプ 1」…。✎ で変更、× で削除）。行をタップするとその位置へ戻ります（ループはしません。字幕行をタップするのと同じ感覚です）。保存した位置はシークバーに白い目印で表示されます。1 本の動画につき 200 個まで。
- **A-B**タブ: A-B ボタンで区間を決めたあと「今の A-B を保存」で名前つき保存（50 個まで）。行をタップするとその区間でループ再生します。最後に使っていた A-B 区間は、その動画を開き直したとき自動で復元します（A-B ボタンで解除）。
- **全画面**ではタイムラインが隠れるため、コントロールに小さな「保存」ボタンが出ます（タイムスタンプを保存するだけ）。設定 →「全画面のコントロールに「保存」ボタンを表示」でオン/オフ（既定オン）。
- すべて動画ごとの記録です（キーは「ファイル名|サイズ|更新日時」。再生位置の履歴と同じ）。
- 自動削除: 設定 →「タイムスタンプ・A-B の記録」で保存期間を 7 日 / 30 日 / 90 日（既定）/ 無制限から選びます。「最後にその動画を開いた日」から数え、過ぎた記録はアプリ起動時と設定変更時に削除されます。
- 手動削除: 各タブの「この動画の記録を削除」、設定の「記録を削除」（全動画）。再生位置の履歴は別管理のため消えません。
- 実装: `www/marks.js`（タブ・画面・ロジック）、`android-shim.js` の `marksGet` / `marksSet` / `marksPrune` / `marksClear` / `marksStats`（localStorage の `mkv.marks`）、`player.js`（A-B との連携）

## スペクトラムアナライザー（イコライザー画面）

- イコライザー画面を開いている間だけ、各フェーダーの背面に実際の音の周波数分布（EQ 適用後）がリアルタイムで表示されます。
- 仕組み: libVLC の音声出力(AudioTrack)を固定の音声セッションに入れ（`--audiotrack-session-id`）、Android の `Visualizer` でその FFT を取得 → 対数 64 本に畳んで JS へ送り、Canvas に描画します。
- 初回だけ「音声の録音」権限（`RECORD_AUDIO`）を求められます。Visualizer の仕様上必要なもので、マイクでの録音は行いません。許可しない場合はアナライザーだけが表示されません（EQ は通常どおり使えます）。
- EQ 画面の「アナライザー」スイッチでオフにできます。EQ 画面を閉じる / 画面が見えなくなると端末側の取得も止まります。
- 端末や音声出力の都合で Visualizer が使えない場合は、画面に理由が出て、アナライザーは表示されません。


## コンプレッサーの入力→出力グラフ

- コンプレッサー画面の上部に、横軸=入力レベル・縦軸=出力レベル(dB)のグラフを表示します。斜めの点線が「何もしない」状態で、折れ線がそこから離れるほど効いています。
- しきい値 / レシオ / ニー / メイクアップを動かすと、ドラッグ中もその場で折れ線が変わります（アタック・リリースは時間方向の動きなので、折れ線には影響しません）。
- 色: 緑=そのまま（メイクアップ分だけ持ち上がる） / 青=ニー（なめらかに移行する範囲） / 赤=圧縮される音。縦の点線がしきい値。
- 白い点は再生中の音の大きさ（目安）。端末側が測った出力レベル(RMS)から、曲線上の位置を逆算して表示します。EQのアナライザーと同じ録音権限(`RECORD_AUDIO`)を使い、コンプ画面を開いている間だけ測定します。8bit の測定のため −48 dB より小さい音では点を消します。
- コンプレッサーがオフのときは、設定の見本を薄く表示し、白い点は点線(入力=出力)の上に出ます。
